# SimonBourdareau.r-universe.dev

Registry for [r-universe](https://simonbourdareau.r-universe.dev), listing R packages by Simon Bourdareau.

## Install

install.packages("brouillet", repos = c("https://simonbourdareau.r-universe.dev", "https://cloud.r-project.org"))

## Packages

- [brouillet](https://github.com/SimonBourdareau/brouillet): reusable colour gradient specifications for ggplot2
